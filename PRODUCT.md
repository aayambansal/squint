# Product

## Register

brand

## Users

Developers who already live in a terminal and already pay for a coding agent (Claude Code, Codex, Cursor). They found squint through GitHub, npm, or a link from a friend. Context: evaluating in under a minute whether this tool deserves an `npx`. The job: understand what squint does, see it working, copy one command.

## Product Purpose

squint is a frontend harness that wraps any coding-agent CLI in the loop that made Lovable work: design brief in, build and runtime errors fed back, screenshots reviewed by the agent itself, all local, on any repo. The landing page exists to demonstrate that loop in seconds and hand over the install command. Success: visitor runs `npx @aayambansal/squint`.

## Brand Personality

Plainspoken, craft-obsessed, a little warm. The product's whole thesis is "non-generic frontend work", so the page must practice what it preaches: nothing that reads as template or AI-generated. Sweet without being cute. Technical without the terminal-goth costume.

## Anti-references

- The dark "developer tool" landing page: black background, glow, purple gradients, mono everywhere.
- The SaaS template: centered hero + badge + three icon cards + stat banner.
- Editorial-serif affectation (italic display serif, ruled columns) on a tool that is not a magazine.
- Everything in docs/research/frontend-quality.md's AI-slop tell catalog. The repo documents these tells; the landing page must contain none.

## Design Principles

- Show the product, not adjectives: the hero is a real squint session playing out.
- One accent, working hard: the TUI's amber (#e8a33d) is the only color voice.
- Every section earns scroll: if a fold doesn't advance "what is it, show me, install it", cut it.
- The terminal is the only dark thing on the page, because that's what a terminal looks like.

## Accessibility & Inclusion

WCAG 2.1 AA. Body contrast ≥ 4.5:1, visible keyboard focus, reduced-motion users get final states instantly (the typing animation is decoration, not information), semantic landmarks, real alt/aria labels.
